# Parameter Extraction Guidelines

To extract parameters from a ceramic capacitor manufacturer description:
1. Locate the Manufacturer Part Number (MPN).
2. Identify the capacitance value (e.g., in pF, nF, µF).
3. Find the case size package designation (e.g., 0402, 0603, 0805).
4. Parse the tolerance value and the operating voltage.
5. Record physical dimensions (length, width, height) if present in the text.
